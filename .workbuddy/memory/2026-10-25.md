## 部署失败排查：wrangler deploy 报 R2 code 10042

- 分支策略：`main` = fork 同步源；`deploy` = CF Workers Builds 部署分支；`backup-main` = 本地备份。
- 现象：sync fork + 手动解决冲突（仅替换 `[[d1_databases]]` 为 jaspermail / 0b186691-…）后，Workers Builds 在 assets 上传后失败：
  `A request to the Cloudflare API (/accounts/6d924118…/r2/buckets/email) failed` + `Please enable R2 … [code: 10042]`。
- 根因：上游提交 8bc20fc（main）把 d1/kv/r2 三块一起取消注释；用户自 2026-08-26 的配置（1b375d9→2f04b45）里 `#[[r2_buckets]]` 是注释态，因此此前部署不声明 R2 绑定。merge 时只替换了 d1 段，R2 段随 main 保留。

- 结论补充：构建容器 `/opt/buildhome/.config/.wrangler/logs/*.log` 不可下载；等价物是 Dashboard → Worker → Deployments → View Build History 的构建日志，或 Builds API `GET /builds/builds/{uuid}/logs`。
