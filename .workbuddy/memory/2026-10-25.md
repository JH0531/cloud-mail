- 依据：wrangler deploy 路径硬编码 `keepSecrets: true`（4.90.0 与 4.152.0 一致），远端 Secret 不会被部署清空；`keep_vars = true` 只覆盖 plain_text/json 绑定。空字符串 var 会把 Secret 降级为 plain_text 空值 → JWT 密钥为空、登录态全失效。

- 注意：Workers Builds 的 "Build variables and secrets" 仅构建期可用，运行时 Worker 读不到，不能用来注入 jwt_secret。
